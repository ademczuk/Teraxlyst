# Code of conduct

Be respectful. Disagree on substance, not people. No harassment, no slurs, no doxxing.

If something is off, open an issue or contact the repository owner (@ademczuk) directly.

This is a placeholder until the project has enough activity to warrant a full Code of Conduct. When that happens, this file will adopt the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
